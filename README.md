# Version 1.0 Market Scanner

A modular Python & Flask market analytics application built on a strict **Single Source of Truth** architecture. The scanner ingests raw market data and order-flow telemetry to evaluate range consolidation, effort/dominance, and breakout readiness.

---

## Architecture Overview

The system enforces strict separation of responsibilities:

1. **Single Source of Truth (`app.py`)**
   - Contains `get_validated_range()`, the sole function authorized to calculate range boundaries (`v_high`, `v_low`, `r_height`), touch counts, containment percentages, and structural validity.
   - Houses the core calculation engines: Status, Battle, Location, Breakout Readiness, and Evidence Synthesis.

2. **Orchestration Layer (`scanner.py`)**
   - Coordinates execution order: Data Fetching → Range Validation → Engine Execution → Table Formatting.
   - Performs zero business logic, scoring, or boundary calculations.

3. **Consumers (`detector.py`)**
   - Consumes `val_range` objects generated by `app.py`.
   - Never re-evaluates ceilings, floors, or range widths independently.

4. **Raw Data Providers (`binance_data.py` & `coinalyze.py`)**
   - `binance_data.py`: Fetches raw OHLCV and volume arrays from Binance Futures.
   - `coinalyze.py`: Fetches raw Open Interest and Funding Rate telemetry, degrading gracefully if API keys are absent.

5. **Presentation Layer (`server.py` & `templates/index.html`)**
   - `server.py`: Runs a Flask server serving the scanner results.
   - `index.html`: Passively renders the approved 7-column matrix (`SYMBOL`, `TIMEFRAME`, `STATUS`, `BATTLE`, `LOCATION`, `BREAKOUT READINESS`, `EVIDENCE`).
